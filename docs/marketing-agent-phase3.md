# Marketing agent (phase 3)

Joins once the agent workforce passes its 4-week checklist gate. Job: posts, case studies and newsletters from finished projects, with client permission recorded in the vault. Needs approval for: every public post, anything naming a client. To switch it on, move a copy of this brief into `.claude/agents/marketing.md` with the same structure as the other agents. The installed `marketing-*` agents in `~/.claude/agents/` (Content Creator, LinkedIn Content Creator, SEO Specialist) are useful references.
