# DEMO sandbox: a fictional day at Gabrion (2026-11-18)

Everything in `demo/` is **fictional**. No business, person, email address or phone number here is real
(phone numbers use Ofcom's drama range 01632 960xxx; emails use example.com/.test). Nothing was sent to anyone.

Paths: in this demo `memory/` = `demo/memory/`, `clients/` = `demo/clients/`. The real `memory/` was not touched.

- `inbox/` — what arrived this morning (chats, emails, an alert, a ticket, a founder request)
- `clients/` — fictional client vaults (intake, discovery notes, signed contracts)
- `memory/` — the demo Command Centre the agents updated (CRM, task board, approval queue, finance, outbox)
- `REPORT.md` — what each agent did, the proof, and the logs

Note: `demo/clients/` is committed on purpose: unlike real `clients/` (git-ignored), everything in it is fictional.
