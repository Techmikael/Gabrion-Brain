# Workflow: client support

**Lead:** operations-support · **Ends with:** a fix and a reply (new fixes and client data changes need approval)

| # | Step | Who | Reviewer | Output |
|---|---|---|---|---|
| 1 | Read the ticket or alert; decide urgency | operations-support | | Priority |
| 2 | Known problem? Apply the run-book fix | operations-support with `support-infrastructure-maintainer` | | Fix log |
| 3 | Unknown or serious? | `engineering-incident-response-commander`, `engineering-sre` | | Cause and options; approval item `new-fix` |
| 4 | Reply to the client | operations-support with `support-support-responder` | `customer-success-manager` | Draft reply |
| 5 | After: what would stop it happening again | operations-support | | Lesson + run-book update proposal |
